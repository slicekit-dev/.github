# Support

- **Purchase or access problems** (invitation missing, wrong GitHub username, billing):
  email [info@slicekit.dev](mailto:info@slicekit.dev).
- **Bugs in the template:** open an issue using the bug report form.
- **How do I...?** Start with the [documentation](https://slicekit.dev/docs). It covers setup, every module and
  common tasks such as adding a permission or a migration.
- **Security issues:** follow the [security policy](SECURITY.md). Do not open a public issue.
