## What you get

An event-driven **.NET 10 API** (vertical slices, DDD, CQRS, messaging) paired with a typed
**React 19 SPA** (TanStack, shadcn/ui). Authentication with passkeys, role presets, invitations,
notifications, GDPR tooling, observability and CI are already wired, so you start on your product
instead of rebuilding the same foundation.

## Getting access

The source lives in a private repository. After you buy a license at
[slicekit.dev](https://slicekit.dev), you are invited to it on GitHub with read-only access, using the
GitHub username you entered at checkout.

1. Accept the invitation from your GitHub notifications or email, or at
   <https://github.com/slicekit-dev/slicekit/invitations> while signed in as that user.
2. Follow the [getting started guide](https://slicekit.dev/docs/getting-started) to scaffold your own project.

The repository stays invisible until you accept the invitation.
